KamelPay AutoFiller

DeepSeek API key

Required. Get one at platform.deepseek.com. The key is stored in this browser profile only and is used from the extension's background worker, so it is never exposed to the pages you fill.

Behaviour

How to use it

  1. Open a KamelPay form — a page form, a modal, or a drawer.
  2. Click the extension icon, or press Alt+Shift+F.
  3. The extension scans the visible form, asks DeepSeek for matching test data, and fills it. Anything it could not fill is listed in the popup.

The extension only reads the tab you invoke it on, and only at the moment you invoke it — it requests no standing access to any site.
